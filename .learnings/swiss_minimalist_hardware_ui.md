# 嵌入式小屏幕 UI 设计：消除 AI 模板感与盒子堆叠的现代极简工程实践

## 1. 产生“劣质 AI 生成感”的核心病因
1. **过度盒模型嵌套（Box Stacking）**：
   - 到处使用实线方框、双层粗黑边框、水泥灰矩形衬底；
   - 未选中的项也用盒子框起来，破坏界面的通透留白；
2. **生硬突兀的局部粗色块**：
   - 卡片左侧直接塞一个 3~4px 宽的纯色竖条；
   - 菜单高亮项整行涂抹高饱和度刺眼色块并反白文字；
3. **无层级排版**：
   - 忽略文字本身的粗细、字号与对比度层级，全部塞进同质化卡片；
   - 字符串过长导致被小屏幕强制折行，压住下一行元素。

## 2. 瑞士现代主义与 Teenage Engineering 工业仪器重塑原则
1. **纯净一体化画布（Unibody Canvas）**：
   - 页面背景贯穿到底（暖白象牙纸感 `0xF8F6F0` 或黑曜深黑 `0x09090B`）；
   - 普通项目不加背景框，自然悬浮在留白中，依靠 1px 微暗分割线（`rule`）和两位数小序号（`01`, `02`）划分节奏；
2. **极轻量聚焦（Subtle Focus State）**：
   - 选中项仅使用极淡的微对比圆角底衬（`COL_CARD_BG`，4px 圆角）；
   - 左侧配以 2~3px 精密瑞士琥珀暖金立柱，右侧配以 2px 精密微圆点指示；
   - 文字保持印刷级炭黑墨色（`COL_INK`），保证第一可读性；
3. **Typography Driven（文字排版驱动）**：
   - 关键指标（Hero Metric）大字居左或居中，不加任何外框，直接呈现大数字；
   - 上方配以小字副标（`TODAY CONSUMPTION`），右侧配以清晰单位；
4. **精密 4px 细滑轨**：
   - 进度条统一使用 4px 细滑轨，底色为极细暗轨，进度为高光强调色，彻底杜绝粗笨进度槽；
5. **硬件仪器感标头与按键轨**：
   - 页面顶部统一采用小写品牌/功能名 + 编号（如 `ai passport 01 / 07`）；
   - 右侧悬浮按键指引轨（UP/DOWN/OK）垂直对齐，整洁克制。
